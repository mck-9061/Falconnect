# AI disclaimer

Parts of Falconnect are developed with the assistance of AI tools, specifically OpenAI Codex. It is used to 
significantly speed up the development process, especially with bug fixing, refactoring, and quick prototyping.
I manually review and edit any generated code. Any code I need to generate largely ends up the same as if I had
written it manually, it just gets there faster.

AI is not used in reverse engineering efforts, nor for text or image generation. It doesn't design any of the
network protocols or overall software design.
